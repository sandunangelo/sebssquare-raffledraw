How to share the sheet so the browser can read it
  1. Open the sheet and press Share.
  2. Under General access choose Anyone with the link, role Viewer.
  3. Copy that link and paste it above.
  4. If your organisation blocks link sharing, use File › Share › Publish to web, pick Comma-separated values (.csv), and paste the published link instead.

The first row may be a header. Put the entrant names in one column and any detail you want shown under the name — department, team or ticket number — in another. A person listed twice gets two chances to win but can still only win once.
